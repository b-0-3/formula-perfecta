# Fórmula Perfecta

Juego para diseñar tu Fórmula 1 ideal: calendario con mapa y nota, reglamento con impactos y simulador con resultados reales (datos de [F1DB](https://github.com/f1db/f1db)).

Se instala en el móvil como una app: abre la web en Safari → Compartir → **Añadir a pantalla de inicio**. Funciona sin internet.

Para actualizar: sube el `index.html` nuevo y cambia el número de versión en `sw.js` (`v1` → `v2`).
